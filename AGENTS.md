# AGENTS.md

This file contains instructions for AI agents working in this repository.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues. Use the `gh` CLI for all operations. See `agents/issue-tracker.md`.

### Triage labels

Five canonical labels map 1:1 to the skill vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `agents/triage-labels.md`.

### Domain docs

Single-context layout: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `agents/domain.md`.

### Available skills

See `agents/skills-reference.md` for a complete list of installed skills, how to invoke them, and common workflows.
